# Huella — Demo PetX

Demo ficticia de una peluquería canina cercana, moderna y natural. Creada con Astro como proyecto independiente para mostrar una identidad visual diferente a la demo Nimo.

## Stack

- Astro 7
- HTML semántico
- CSS moderno
- JavaScript mínimo (vanilla)

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Datos editables

Toda la información del negocio está centralizada en `src/data/site.json`.

## Estructura

```text
src/
├── components/
├── data/
├── layouts/
├── pages/

```
