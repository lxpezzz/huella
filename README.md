# Huella — Demo PetX

Demo ficticia de una peluquería canina cercana, moderna y natural. 

## Stack

- Astro 7
- HTML semántico
- CSS moderno
- JavaScript mínimo (vanilla)

## Datos editables

Toda la información del negocio está centralizada en `src/data/site.json`.

## Estructura

```text
src/
├── components/
├── data/
├── layouts/
├── pages/
├── scripts/
└── styles/
```
